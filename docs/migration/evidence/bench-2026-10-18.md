# Benchmark local: Python vs Rust (2026-10-18)

> **Alcance y límites.** Medido en un Mac (arm64, 8 GB), macOS, **RSS de macOS** (no comparable en valor absoluto con Linux), MariaDB 12.3 local, build `--release`.
> Sirve para **comparar proporciones**, no como cifra de producción. La línea base real del servidor (TASK-0001) **sigue pendiente**.
> Reproducir: `cd back-rs && cargo build --release && RS_PROFILE=release python3 bench/bench.py --requests 3000 --threads 16`.

## Lectura honesta de los resultados
- **Rust en reposo ≈ 7 MB** (la primera medición, antes de precalcular el hash señuelo de Argon2, era 73–149 MB porque calculaba un hash de 64 MiB al arrancar; ese cálculo ya no ocurre).
- **Tras el primer login Rust queda ≈ 73 MB en macOS**: el hash Argon2id necesita 64 MiB transitorios (parámetros que deben conservarse para verificar los hashes existentes) y el asignador de macOS no los devuelve al sistema. En Linux (glibc, mmap) los bloques grandes suelen liberarse al terminar → **debe medirse en el servidor** (TASK-0046 queda abierta para eso).
- **Pico con 8 logins simultáneos:** Rust 75 MB (semáforo `ARGON2_CONCURRENCY=1` serializa los hashes) vs Python 560–634 MB (cada login simultáneo reserva sus 64 MiB).
- **Python devolvió 5xx bajo carga concurrente** (≈15–20 % de las peticiones; error MariaDB 1020 «Record has changed since last read» con `innodb_snapshot_isolation` activo en MariaDB 12.3) y sus hilos de carga terminaron antes (por eso completó menos peticiones). **Rust: 0 errores** (aislamiento `READ COMMITTED` + reintento de transacción ante 1213/1205/1020). Si producción usa MariaDB ≥ 11.8 este fallo del backend actual podría existir ya; **no verificado en producción**.
- Los req/s y latencias de Python **no son comparables** (muchas peticiones fallaron); los de Rust se midieron con 0 errores en el mismo generador de carga (que es Python con hilos y limita el máximo).
- La primera ejecución del benchmark (antes del ajuste del señuelo) dio para Python 1 worker 149 MB en reposo y 2 workers 340 MB tras arrancar; la variación entre ejecuciones de Python en reposo (25–149 MB) no se investigó; la conclusión (Rust en reposo ≪ Python) no cambia.
